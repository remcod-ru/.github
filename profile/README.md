# REMCOD

**Дизайн, ремонт и цифровая среда для строительных проектов.**

_Design, construction, and an ERP platform for designers and builders._

REMCOD объединяет компанию полного цикла по дизайну и ремонту с собственной
ERP-платформой. Мы связываем проектирование, сметы, финансы, задачи, документы,
коммуникации и контроль исполнения в одной рабочей среде — для дизайнеров,
строителей, прорабов, подрядчиков и заказчиков.

## Два контура одной системы

- **Дизайн и реализация.** Проектируем интерьеры и выполняем ремонт под ключ с
  прозрачной сметой, контрольными датами, поэтапной приёмкой и отчётностью.
- **REMCOD ERP.** Создаём цифровой контур строительного проекта: от лида и
  дизайн-проекта до сметы, закупок, производства работ, финансов и сдачи объекта.
- **REMCOD Project.** Развиваем рабочую среду для обмеров, планировок, инженерных
  листов, ведомостей и передачи проекта в реализацию без повторного ввода данных.

## Публичная инженерия

- **[REMCOD Agent Runtime](https://github.com/remcod-ru/remcod-agent-runtime)** —
  открытый provider-neutral runtime и test harness для надёжных AI-агентов.

## Принципы

- одна актуальная версия проекта для всей команды;
- прозрачные деньги, сроки и ответственность;
- проверяемые действия и безопасная автоматизация;
- технология поддерживает специалиста, а не подменяет его полномочия.
