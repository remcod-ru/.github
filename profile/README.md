# REMCOD

**Компания по дизайну и ремонту. Разрабатываем ГЕНПОДРЯД — платформу для дизайнеров, строителей и заказчиков.**

_Design and renovation company behind GENPODRYAD, a platform for designers, builders and clients._

REMCOD — компания полного цикла по дизайну и ремонту. Мы разрабатываем
[ГЕНПОДРЯД](https://buildgen.ru) — собственную платформу, которая связывает
проектирование, сметы, финансы, задачи, документы, коммуникации и контроль
исполнения в одной рабочей среде — для дизайнеров, строителей, прорабов,
подрядчиков и заказчиков.

## Два контура одной системы

- **Дизайн и реализация.** Проектируем интерьеры и выполняем ремонт под ключ с
  прозрачной сметой, контрольными датами, поэтапной приёмкой и отчётностью.
- **ГЕНПОДРЯД.** Создаём цифровой контур строительного проекта: от лида и
  дизайн-проекта до сметы, закупок, производства работ, финансов и сдачи объекта.
- **Проектирование в платформе.** Развиваем рабочую среду для обмеров, планировок,
  инженерных листов, ведомостей и передачи проекта в реализацию без повторного
  ввода данных.

## Публичная инженерия

- **[REMCOD MCP plugin](https://github.com/remcod-ru/remcod-plugin)** — MCP-сервер
  и Skills для Codex и Claude Code: проекты, сметы, отчёты, финансы и файлы
  платформы ГЕНПОДРЯД.
- **[REMCOD Agent Runtime](https://github.com/remcod-ru/remcod-agent-runtime)** —
  открытый provider-neutral runtime и test harness для надёжных AI-агентов.

## Принципы

- одна актуальная версия проекта для всей команды;
- прозрачные деньги, сроки и ответственность;
- проверяемые действия и безопасная автоматизация;
- технология поддерживает специалиста, а не подменяет его полномочия.
